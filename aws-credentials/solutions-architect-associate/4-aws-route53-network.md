# 1. AWS S3 Bucket

`S3`는 오브젝트 객체의 형식으로 데이터를 저장하고 데이터 레이크, 웹 사이트, 모바일 애플리케이셔느 백업 및 복원, 아카이브 등 다양한 사용 사례에서 등장하듯이 원하는 규모와 양의 데이터를 저장하고 액세스를 최적화해 하나의 구조화 및 구성할 수 있는 관리 기능 서비스이다.

## 1.1 S3 기능

여러 사용 사례의 지표가 존재하는 원하는 맞춤 스토리지 클래스를 제공하고 잦은 액세스를 하기 위해 미션 크리티컬 프로덕션 데이터를 S3 Standard 또는 S3 Express One Zone에 저장하고, S3 One Zone-IA에 저장하여 비용을 절감할 수 있다. S3 Glacier Flesible Retrieval 또는 Deep Archive에 가장 낮은 수준의 비용으로 데이터를 보관할 수 있는 방법이 마련되어 있다.

하지만 `S3 Express One Zone`은 자연 시간에 노출되어 있는 가장 민감한 애플리케이션에 대해 일관된 시간 미만의 데이터 액세스를 제공하도록 맞춤 설계된 고성능 단일 영역 Amazon S3 Storage Class이다. 현재 사용 가능한 클라우드 객체 스토리지 클래스 중 지연 시간이 가장 낮아 S3 Stanard보다 데이터 액세스 속도는 최대 10배까지 빠르게 요청을 하여 그에 대한 비용 발생을 50%까지 저렴하게 최적화 할 수 있다는 장점을 가질 수 있다.

객체 스토리지를 컴퓨팅 리소스와 함께 배치하는 옵션을 제공하면서도 단일 가용 영역 선택이 가능한 최초의 스토리지 클래스로 빠른 액세스 속도를 제공하는 서비스이기에 동시 요청수와 광범위한 요청을 지원하기 위함으로 데이터는 새로운 버킷 유형인 디렉터리 버킷에 저장된다.

* S3 Standard
* S3 Express One Zone
  * S3 Glacier Flesible Retrieval
  * S3 Glacier Deep Archive
